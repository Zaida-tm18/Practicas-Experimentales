# 🐾 VetSystem - Práctica Experimental Unidad I

Aplicación web desarrollada como parte de la **GA – Práctica Experimental Unidad I** de la asignatura **Aplicaciones Web – 5to Nivel** en la Universidad Técnica Estatal de Quevedo.

## 📖 Descripción

**VetSystem** es un sistema de gestión veterinaria desarrollado con tecnologías web modernas.
Permite registrar mascotas, almacenar pacientes localmente y mostrar información dinámica consumida desde una API pública.

El proyecto aplica:

  ✅ HTML5 semántico

  ✅ CSS3 responsivo con Grid y Flexbox

  ✅ JavaScript ES6+ modular

  ✅ Consumo de API pública (`Dog CEO API`)

  ✅ Validaciones accesibles y almacenamiento local (`localStorage`)

  ✅ Auditorías de accesibilidad y rendimiento con Lighthouse y WAVE

## 🛠️ Tecnologías utilizadas

- **Dog CEO API** – Obtención dinámica de razas caninas.
